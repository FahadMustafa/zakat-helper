# Zakat Helper

Work out your yearly zakat in the browser. Record what you hold on your zakat date, see what is due, and track what you have paid until the year is settled. Arabic and English, Hijri and Gregorian dates.

**Private by design.** There is no server and no account. Your data stays on your device: you keep it in a file you save and open, and nothing is sent anywhere.

Zakat Helper is a calculator, not a fatwa. It shows which settings produced each figure so you can check them against your own scholar's view.

Status: in development.

## Development

```bash
npm install
npm run dev       # local dev server
npm run verify    # typecheck, lint, format check, tests, build
npm run deploy    # build and deploy to Cloudflare (needs wrangler login)
```
